# word-doc-normalizer

面向科技期刊编辑流程的 DOCX 本地规范化与质检工具。

## 当前版本

V5.1（编辑安全版）

- 文档模型 → 分阶段规则引擎 → 完整性守卫 → 输出 DOCX 二次自检 → 质检结果
- 浏览器本地处理 DOCX，稿件内容不会上传到服务器
- 自动执行已确认的确定性格式规则
- 引文序列：连续序号用短横线，不连续序号用中文逗号，例如 `[1][2] → [1-2]`、`[1][10] → [1，10]`
- Word 自动列表转为普通文本；参考文献输出为 `[1] 作者……` 普通段落
- 支持小标题与说明段合并、中文双引号、数字与单位空格、数字三位分节等规则
- 日期连接符、普通数值范围等高风险内容保持原文，不擅自修改
- 保护图片、表格、公式、MathType/OLE、域、书签等 OOXML 结构
- 如果受保护对象减少，或导出的 DOCX 无法重新打开、媒体/嵌入对象/关系文件集合变化，直接阻止下载
- 对图表正文引用等不宜自动决定的项目给出人工确认提示

## 使用

打开仓库根目录的 `index.html`。启用 GitHub Pages 后，可直接通过固定网页入口使用。

## 源码结构

```text
index.html
styles.css
src/
  docx-core.js      # OOXML/DOCX 结构操作
  format-rules.js   # 确定性格式规则与质检规则
  engine.js         # RuleEngine / IntegrityGuard / 输出包自检 / AuditEngine
  ui.js             # 浏览器交互

docs/
  architecture.md
```

## 隐私与测试数据

仓库只保存工具源码、规则与说明文档。未发表稿件、作者原稿、正确版 DOCX 和真实黄金回归样本不提交到公开仓库；这些测试材料仅用于本地回归。

## 依赖

当前网页从 jsDelivr 加载 JSZip 3.10.1；DOCX 文件本身仍只在浏览器本地内存中处理。
